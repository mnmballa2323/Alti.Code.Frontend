## 📖 Overview
Alti.Code.Studio is not just an IDE; it is a **Universe** of specialized AI Agents working in concert to accelerate software delivery while ensuring governance, security, and cost efficiency.

It bridges the gap between:
-   **Creation** (Developers on Desktop)
-   **Control** (Admins on Web)

## 🏗️ Architecture "The Universe"
The system is composed of localized "Planetary" Agents:

| Agent | Role | Responsibility |
|-------|------|----------------|
| **The Architect** | Orchestrator | Coordination & Planning |
| **The Overseer** | DevOps | CI/CD Pipelines |
| **The Sentinel** | Security | Vulnerability Scanning |
| **The Auditor** | Finance | Cost Tracking |
| **The Weaver** | Git | Version Control |
| **The Polyglot** | i18n | Localization |
| **The Librarian** | Docs | Auto-Documentation |
| **The Analyst** | BI | Data Visualization |

## 🚀 Key Features
-   **Unified RBAC**: secure separation of Admin/User routes.
-   **Smart Scaffolding**: AI-driven project generation.
-   **Compliance Dashboard**: Real-time license & security monitoring.
-   **Global Reach**: Native translation support.

## 🛠️ Installation & Setup

### Prerequisites
-   Node.js v20+
-   Redis (Synapse Layer)
-   Git

### Quick Start
1.  **Clone the Universe**:
    ```bash
    git clone https://github.com/mnmballa2323/alti.code.studio.git
    cd alti.code.studio
    ```

2.  **Initialize Environment**:
    ```bash
    # Windows
    ./setup_env.ps1
    ```

3.  **Launch Backend**:
    ```bash
    cd alti.code.studio.backend
    npm install
    npm run dev
    ```

4.  **Launch Frontend**:
    ```bash
    cd ../alti.code.studio.frontend
    npm install
    npm run dev
    ```
