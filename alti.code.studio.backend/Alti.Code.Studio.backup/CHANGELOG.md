## [0.1.0] - 2026-02-04
### Added
-   **Borg Agentic Engine**: Implemented `Director` (Orchestrator) and `Maestro` (Swarm Manager) to enable autonomous agent swarms using Git Worktrees.
-   **Grand Unification**: Added integration tests to verify the Borg Engine lifecycle.
-   **User Preferences**: Implemented "Memory" settings toggle and Theme selection in new `/settings` page. Added `preferences` field to User model and integration with backend.
-   **Agent Store**: Implemented backend module (Model, Service, Controller, Routes) and frontend UI (Page, Components, Service) for browsing and installing AI agents.
-   Initial project re-analysis and roadmap documentation.
-   Created `AGENTS.md` and model-specific instruction files.
-   Standardized `package.json` metadata.
